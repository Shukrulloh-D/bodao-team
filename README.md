# Задание

Сверстать сайт школы бокса «Франсимара Бодао Барросо» — персональные и групповые тренировки по боксу под руководством тренеров Бодао и Барросо. Сайт состоит из одной ключевой страницы «Главная» (лендинг).

# Страница «Главная»

* шапка с логотипом школы (круглая эмблема), контактным телефоном/адресом и иконкой связи/личного кабинета справа;
* hero-блок на всю ширину с чёрно-белым фото боксёра в стойке, крупным заголовком «ФРАНСИМАРА БОДАО БАРРОСО» и кнопкой-CTA (оранжевая);
* блок «О ШКОЛЕ» — фото зала/интерьера слева, круглая декоративная фотовставка боксёра поверх основного фото, текстовое описание философии школы справа, кнопка-CTA;
* блок «ТРЕНЕРЫ» — две карточки тренеров (Бодао, Барросо) с фото в полный рост, именем и коротким описанием под каждой карточкой;
* блок «НАПРАВЛЕНИЯ» — горизонтальная лента из 4 фото-карточек с направлениями/дисциплинами (бокс, работа на снарядах, спарринг, женский бокс и т.п.), подпись категории поверх фото;
* блок «РАСПИСАНИЕ ЗАНЯТИЙ» — сетка карточек абонементов (1 день, 1 месяц, 2 месяца, 4 месяца, 6 месяцев, 1 год), в каждой карточке: название периода, краткое описание, цена (например «41 799 Р») и оранжевая кнопка записи/покупки;
* блок «БЛОК ИНСТАГРАММА» — сетка фотографий (3 колонки, несколько рядов) из чёрно-белых снимков тренировок, стилизованная под ленту Instagram;
* футер — логотип школы, блок с адресом/контактами, две колонки текстовых ссылок (например: расписание, тренеры, направления / о школе, контакты, полезная информация) и иконки соцсетей внизу.

# Адаптивность

Сайт должен быть адаптивным, для каждого блока предусмотрена мобильная версия:

* десктоп — полноширинные блоки, карточки тренеров и направлений в ряд, сетка расписания в 3 колонки;
* планшет (iPad mini) — сужение hero-блока, карточки тренеров и направлений по 2 в ряд, расписание занятий — по 2 карточки в ряд;
* мобильная версия — все блоки в один стек (одна колонка), сокращённые заголовки, карточки расписания друг под другом, инстаграм-лента в 2 колонки.

# Дизайн

Тёмный (чёрно-графитовый фон), контраст за счёт чёрно-белых фотографий боксёров, акцентный цвет — оранжевый (кнопки CTA, логотип, цены). Скруглённые карточки, минималистичная типографика, крупные фото как основной визуальный акцент.
